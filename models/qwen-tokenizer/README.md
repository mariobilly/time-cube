# Qwen tokenizer

The tokenizer of the Qwen2.5 / Qwen3 models (vocab.json, merges.txt, tokenizer_config.json), as ComfyUI ships it
(`comfy/text_encoders/qwen25_tokenizer`) and uses for Qwen3-VL. Time Cube's captions (`caption.py`) read it from here.

These files are by the Qwen team (Alibaba Cloud), from the Qwen2.5-VL / Qwen3-VL releases on Hugging Face, and are
